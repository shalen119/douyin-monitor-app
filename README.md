# 抖音视频舆情监测试点

本机网页 + 常驻服务。手工添加公开抖音视频，监测页面显示的点赞量、评论总数及浏览器实际读到的评论。评论命中词、数值阈值和飞书提醒可在「设置」配置。

## 双击安装与启动（Windows）

1. 解压安装包到固定目录，例如 `D:\DouyinMonitor`。首次安装需要联网。
2. 双击 **`双击安装环境.cmd`**。它会检查 Node.js 24+ 和 Microsoft Edge；若缺少 Node.js，会从 Node.js 官网下载到本程序的 `.runtime` 目录并校验 SHA-256，不改系统 PATH；若缺少 Edge，会尝试用 Windows 自带的 `winget` 安装。随后自动运行 `npm ci` 安装项目依赖。安装完毕后可关闭安装窗口。若 Edge 自动安装受电脑权限或 `winget` 限制，窗口会给出官网下载地址，安装 Edge 后再双击本文件。
3. 双击 **`启动抖音监测.cmd`**，保持运行窗口打开。脚本会自动打开 `http://127.0.0.1:4318/`；若服务已在运行，会直接打开已有页面。页面只监听本机回环地址。
4. 在「设置」点「打开抖音登录」，在弹出的**应用专用 Edge 浏览器**中自行扫码或输入验证码。完成后点「验证登录并恢复」。之前在其他浏览器中的登录不会自动转入此会话。
5. 在「监测视频」粘贴视频链接。可输入 `https://www.douyin.com/video/...`，也可输入包含 `https://v.douyin.com/...` 的分享文案；每行一条。
6. 在「设置」填写检查间隔、历史补采上限、用「、」分隔的命中词、分开的点赞量与评论总数阈值、飞书群自定义机器人 Webhook。如启用飞书签名校验，同时填入签名密钥。每项可点旁边「应用」，顶部出现 1.5 秒保存提示；也可点「保存设置」。随后点「发送测试提醒」，检查手机飞书。

同一目录只需安装一次；以后直接双击 `启动抖音监测.cmd`。安装脚本仅为本次运行临时允许 PowerShell 执行，不修改系统执行策略。已有合格的 Node.js 和 Edge 会直接复用。项目依赖保存在 `node_modules`，Node.js 本地副本保存在 `.runtime`；两者随程序目录一起移动。也可手工使用 `npm ci`、`npm start`。

关掉运行服务的命令行窗口、电脑休眠或断网时，监测会停止。再次启动会读取 `data/monitor.sqlite` 和 `data/browser-profile/`，继续未暂停的视频。请勿向他人分享这两个文件夹：其中保存评论、Webhook 和浏览器登录会话。

采集时 Edge 会保留最近检查的视频页面，不会在采集结束后关闭最后一个视频窗口。手动关闭 Edge 后，下一次检查会重新打开应用专用浏览器；若抖音登录本身已经失效，仍需在「设置」重新登录。

## 可控采集与数据解释

- 每条视频可单独暂停、恢复、立即检查、删除。列表顶部可全选或逐条勾选，批量删除和修改间隔。删除会级联清除本机保存的该视频评论、观测和提醒。
- 首次历史评论补采达到每条视频上限后停止。暂停后恢复的评论另作补采；新评论继续检查。
- 抖音页面显示 `3.2万` 时，页面和飞书保留 `3.2万`。阈值比较约按 32000，临界值可能有舍入误差。
- 「监测视频」同时显示点赞量和平台评论总数相对首次采集的净变化；含「万」「亿」的增量会标注「约」。增量为负数表示页面显示值减少。
- 「评论总数」是抖音显示值；「已采」是本机实际保存条数。两者不会混同。
- 日、周、月统计按首次发现时间（北京时间）归档。首次历史补采单列，不算当期新增评论。
- 词库变更只重新匹配本机已存评论。仅新增命中的评论按视频汇总提醒。
- 新采评论按集中词库做字面包含匹配，命中后按视频汇总。点赞量或评论总数达到各自阈值时，飞书提醒带作品名称、链接、当前显示值及相对首次采集的增量。未配置飞书时提醒留在本机。
- 飞书发送失败后保留待发送记录，并按退避间隔重试。Webhook 不会通过页面状态接口回显。

## 已知限制与待验证项

当前适配器只观察官方抖音网页自身加载的视频详情和评论列表；不直接调用平台内部接口、不绕过验证码或防护。页面结构变化可能使采集失败，失败会显示在「运行状态」。

2026-10-24 对[示例视频](https://www.douyin.com/video/7673152596441304358)实测：未登录时页面显示点赞 `3.2万`、评论总数 `343`，一次读到 9 条可见评论，页面仍提示需要登录。随后在应用专用浏览器登录，首次补采保存 181 条主评论；重启服务后登录会话和 181 条数据仍在，再次检查没有重复入库。页面仍显示总评论数 `343`，因此标为「部分评论未读取」。首版只采集页面评论列表中已加载的主评论，未展开的回复可能缺失；不会声称已采齐平台总数。长时间定时稳定性仍需持续观察。暂停期间已删除或平台不再提供的评论无法追回。

飞书真实送达需要你提供 Webhook 并发送测试提醒；未配置时提醒会留在本机待发送。

## 开机启动

可在 Windows「任务计划程序」创建“用户登录时”任务，操作指向本目录 `启动抖音监测.cmd`。先手动启动并验证登录、采集和飞书，再启用开机任务。不要同时启动两个服务实例：它们不能共用同一浏览器登录目录。

## 开发验证

运行 `npm test`。测试覆盖规则解析、SQLite 持久化和级联删除、历史补采与新评论分类、重匹配、阈值提醒、飞书失败退避、本地 API，以及浏览器中的主要交互。
